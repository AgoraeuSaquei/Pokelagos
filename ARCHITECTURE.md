# Arquitetura

Aplicação web HTML/CSS/JavaScript. index.html é a entrada; style.css trata apresentação; app.js integra a interface; engine.js contém a simulação; data.js contém dados; narrative.js trata narrativa; scenes.js e visuals.js tratam apresentação visual. assets contém recursos. build.py gera a distribuição standalone. Consulte o código para contratos específicos.

Testes existentes: test.js, test-smoke.js, test-battles.js, test-bonds.js, test-connected.js, test-ecology.js, test-growth.js, test-league.js, test-narrative.js, test-visuals.js, test-world.js e test-browser-v21.py. Validar requisitos e execução antes de cada entrega.
